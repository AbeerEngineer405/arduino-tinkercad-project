# Arduino Circuit Project – Smart Methods Training

This project was created as part of the **Smart Methods Training Program**.

The circuit was designed and tested using **Tinkercad Circuits** to practice Arduino programming and electronic circuit simulation.

## Project Objectives

- Learn the basics of Arduino programming.
- Build and connect electronic components.
- Write and test Arduino code.
- Simulate the circuit using Tinkercad.
- Understand how hardware components interact with Arduino.

## Tools Used

- Arduino
- Tinkercad Circuits
- Arduino IDE
- C/C++ for Arduino programming

## Tinkercad Project

You can view and test the project using the following link:

https://www.tinkercad.com/things/k1RJ6YtrR9O/edit?sharecode=Zg9ki9wPy_60TlhBrSNpnoqhSiDM3UtTYWCgtgO9lww

## How to Run the Simulation

1. Open the Tinkercad project using the link above.
2. Sign in to Tinkercad if required.
3. Open the circuit design.
4. Click **Start Simulation**.
5. Observe the Arduino circuit behavior.
